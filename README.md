# Fuerza

A small offline web app (PWA) for planning and logging home strength sessions for a runner. It works with kettlebells, dumbbells, bands, a pull-up tower, a plyo box and a jump rope.
The interface is in Spanish and the exercise names are in English.

Open it in Chrome on Android, then use "Añadir a pantalla de inicio" to install it. Workout logs stay on the device, in IndexedDB.
